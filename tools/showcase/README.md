# Screenshot showcase (not part of the mod)

A helper mod that builds a dark cave room lit by glowshrooms and lamps at y = -200 and puts the
player in front of it with the HUD hidden. For ContentDB / README screenshots:

1. Copy this folder to your Luanti `mods/` folder as `glowshroom_showcase`, and install
   `glowshroom` and `xcompat` (or use ContentDB in the main menu).
2. Create a Minetest Game world, enable the three mods, and join it.
3. Wait a few seconds, press F12, and find the PNG in Luanti's `screenshots` folder.
